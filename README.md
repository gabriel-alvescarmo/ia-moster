# 🤖 IA no Servidor - Site com Ollama Embutido

Site de inteligência artificial **100% auto-contido**. A IA roda DENTRO do próprio servidor, sem APIs externas, sem chaves, sem banco de dados e sem nada instalado no computador do visitante.

---

## ✨ Funcionalidades
- 💬 Chat em texto com respostas em tempo real (streaming)
- 🎤 Falar com a IA por voz (reconhecimento de fala)
- 🔊 IA responde em voz alta (síntese de fala)
- 🧠 IA roda no servidor via **Ollama**
- 🔒 Zero dados salvos (conversa some ao fechar a aba)
- 📱 Responsivo (funciona no celular)
- 🚀 Deploy com 1 clique

---

## 🛠️ Tecnologias
- **Ollama** - Executa os modelos de IA
- **Flask** - Backend web em Python
- **Docker** - Empacota tudo junto
- **Tailwind CSS** - Interface bonita
- **Web Speech API** - Voz nativa do navegador
